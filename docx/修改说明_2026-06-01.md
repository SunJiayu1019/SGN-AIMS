## 问题 1：审批通过后 house_info.geometry 乱码

### 错在哪
- `sys_area.geometry` 在数据库里是 **MySQL 的 `POINT`（空间/二进制）类型**；
- 但实体 `SysArea.geometry` 是 **Java String**，`house_info.geometry` 是 **VARCHAR(100)**；
- 审批通过入库时（`ApplyAuditServiceImpl.enterHouse`）直接
  `house.setGeometry(streetArea.getGeometry())`：
  MyBatis 把 `POINT` 的 **WKB 二进制字节** 读进 String，再原样写进 `house_info.geometry`，
  于是库里就是一堆乱码字节。
- 你的判断完全正确：就是「数据库里是 point 类型，实体里是 String 类型」导致的。
- 另外还有个隐藏问题：`sys_area.lng/lat/geometry` 从来没被赋过值（街道级全是 NULL），
  即使不乱码，新门牌也拿不到坐标。

### 怎么改
1. **后端**（`service/impl/ApplyAuditServiceImpl.java`）：
   不再拷贝二进制 geometry，改成用经纬度现拼标准 WKT 文本：
   ```java
   house.setGeometry(buildWkt(lng, lat)); // "POINT(112.55 37.87)"
   ```
   并新增私有方法 `buildWkt(String lng, String lat)`。
2. **数据库**（执行 `sql/fix_geometry_2026_06_01.sql`）：
   - 把 `sys_area.geometry` 从 `POINT` 改成 `VARCHAR(100)`，统一存 WKT 文本；
   - 给省/市/区县/街道补上 `lng/lat/geometry` 演示坐标（街道用上级中心点兜底）；
   - 把 `house_info` 里已写坏的 geometry 用 lng/lat 重建，乱码的清空。

> 结论：geometry 在本项目里**一律按 WKT 文本（VARCHAR）处理**，不要用 MySQL 的 POINT 类型，
> 否则 String 实体读到的就是二进制乱码。

## 问题 2：行政区划管理 导出省/市/区县/街道专题地图

### 怎么实现（你的疑问：要用 GIS 吗？要新建表吗？）
**都不需要。** 专题地图 = 地理底图 + 专题层（按某个统计量着色/分级）。
本系统的统计量就是「各区域门牌数量」，数据已经在 `house_info` + `sys_area` 里，
不必上 GIS 服务器，也不必新建表。

### 怎么改
1. **后端**（`controller/GisController.java` 新增 `/api/gis/thematic?level=`）：
   按层级（1省/2市/3区县/4街道）把门牌数量**上卷累计**到每个区域，
   并返回区域中心经纬度，供前端着色打点。
2. **前端**（`views/admin/AreaManage.vue`）：
   新增「📊 导出专题地图」按钮 + 弹层，用项目已有的 **echarts** 依赖
   画分级符号专题图（数量越多点越大、颜色越深），
   并用 echarts 原生 `getDataURL()` **导出 PNG**。
   可切换 省/市/区县/街道 层级。

> 进阶（可选）：若以后要做「按行政边界面状填色」的标准 choropleth，
> 再引入 GeoJSON 边界文件 + echarts `registerMap` 即可，仍不需要 GIS 服务器。

## 问题 3：门牌管理 中心缓冲查询 / 矩形缓冲查询

### 能实现吗？怎么实现
能。不需要数据库空间函数，纯后端计算即可：
- **中心缓冲**：给圆心 + 半径(米)，用 **Haversine 球面距离**算每个门牌到圆心的距离，≤半径即命中；
- **矩形缓冲**：给矩形对角两点，判断门牌经纬度是否落在包围盒内。

### 怎么改
1. **后端**（`controller/GisController.java` 新增）：
   - `GET /api/gis/buffer/center?lng=&lat=&radius=&areaId=`（圆形缓冲，返回结果含距中心米数）；
   - `GET /api/gis/buffer/rect?minLng=&minLat=&maxLng=&maxLat=&areaId=`（矩形缓冲）。
2. **前端**（`views/admin/HouseManage.vue`）：
   新增「🛰 缓冲查询」面板，基于 **Leaflet**：
   - 中心缓冲：地图上点击设圆心，输入半径，画圆并列出命中门牌；
   - 矩形缓冲：地图上拖拽框选矩形，画框并列出命中门牌。
